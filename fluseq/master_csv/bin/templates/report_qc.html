Assessment rules and interpretation

  • Run success / failure: a recognised subtype in the final Sekvens_Resultat counts as called. Empty, missing or unrecognised final results count as no call, even if a raw Subtype exists. When the final-result column is absent, recognised raw subtypes require HA and NA coverage ≥30%, matching the upstream gate. These rates measure subtype-call yield, not laboratory approval.
  • qPCR: only Påvist, ignoring case and surrounding spaces, is positive in the assay fields. Negative, missing, multiple-positive and unrecognised results are distinguished. No subtype mismatch is inferred from missing qPCR or a missing sequencing call. Master rows are indexed by Prove_LW_ID, with sequencing IDs used when it is missing. FASTQ joins Sample to the sequencing ID; FASTA matches OriginalName or SampleID through exact master identifiers, including legacy Key. Ambiguous matches are rejected. Identifiers remain text.
  • Mixed sites: review when the segment count is strictly >@@MIXED_THRESHOLD@@. Repeated segment counts in HA1/HA2 and M1/M2 are not summed. If copies disagree, the largest valid count is used for review and the disagreement is flagged in Details.
  • IRMA noise: review when IRMA_noise is strictly >@@NOISE_THRESHOLD@@. This is the reported alternate-match / match read ratio. Missing or invalid values remain unavailable.
  • Reported QC: NGS_QC_Sum is preserved. An empty cell means no reported flags; a missing column or NA-like value means unavailable. Source codes: LC = low or missing coverage; FS = frame shift; MS = mixed sites. The existing source rules use coverage <80% and mixed-site sum >3.
  • Segment outcomes: coverage ≥@@COVERAGE_THRESHOLD@@% passes this screen, coverage below that fails, and missing/invalid values have a separate category. The default 80% retains the existing pipeline criterion. This is consensus non-N content, not a depth or full-reference breadth measurement. Values outside 0–100% are invalid. Medians exclude unavailable measurements and retain zero.
  • Other QC: the existing NGS summary, Nextclade QC, GISAID comments, characterisation, subclade evidence, reported reassortment screen and drug lookup codes remain available. Missing measurements do not mean zero. The report does not change any source calls or master values.
  • Findings: characterisation and subclade labels describe reported genetic categories. Reassortment conclusions are similarity-screen flags. Drug lookup codes are displayed as reported. These fields do not establish antigenic phenotype, confirmed reassortment or clinical drug susceptibility.
