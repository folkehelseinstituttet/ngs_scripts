Local HA analyses of influenza A/H5N1 and A/H5N5 from supplied GISAID metadata
and HA sequences. Each dataset contains one subtype, with a minimum sampling
date of 2024 and the filters specified in the local HA configuration.

H5N5 uses the upstream H5Nx HA reference and display resources. The upstream
workflow does not add clade labels for the h5n5 build name; existing metadata
annotations are retained.
